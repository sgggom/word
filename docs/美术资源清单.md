# 美术资源清单

游戏里目前**没有任何图片文件**，所有视觉都是代码画的：

- **图标**：`index.html` 第 38–50 行手写的内联 SVG（9 个线条图标），通过 `<use href="#i-xxx">` 引用，颜色跟随 `currentColor`
- **纹理**：`style.css` 里用 SVG 滤镜（`--noise`、`--fibers`）实时生成的纸张噪点和纤维
- **皮革封面、书页厚度、字砖立体感**：CSS 渐变 + 多层 `box-shadow` 叠出来的
- **小装饰**：Unicode 字符（★ ✓ ✎ ✦ ○ ✗）

以下按优先级列出建议替换的资源。尺寸均给出**交付尺寸**（已含 2x/3x 高清倍率），显示尺寸写在括号里。

## 四、字砖（棋盘上的字母块）

字砖尺寸是动态的：**40–92px**（桌面最大 92，手机最大 78）。字母和右上角剩余次数由代码写，**底图不要带字母**。

建议交付 **288×288 PNG 透明底**（92px × 3），做成可以 9 宫格拉伸的方块。

| 状态 | 提示词 |
| --- | --- |
| 普通 | `blank square letterpress type tile, ivory cream #f8f1e1 paper surface, slightly raised with soft bottom shadow, rounded corners, top-down, transparent background, no letter` |
| 选中（按下） | 同上，`pressed down, slightly darker #efe2c4, inner shadow` |
| 幕布（被盖住） | `square tile covered with diagonal hatched cloth, muted brown, top-down, transparent background` |
| 用完消失 | 不需要图，代码会淡出 |

## 交付格式小结

| 类型 | 格式 |
| --- | --- |
| 图标、花饰 | **SVG 优先**（单色）；否则 144×144 PNG 透明底 |
| 平铺纹理 | 512 或 1024 正方形，无缝，PNG/JPG |
| 封面、字砖、印章 | PNG 透明底，按上表 3x 尺寸 |
| App 图标 | 1024×1024 PNG |

文件放到 `assets/` 目录下，命名沿用上表 ID（如 `i-feather.svg`、`tile-normal.png`），交过来我来接进代码。
